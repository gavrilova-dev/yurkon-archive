# YURKON Archive

Локальное Windows-приложение для учёта организаций, первичной документации, архивных индексов и сканирования PDF.

## Возможности
- Локальная база SQLite в профиле пользователя.
- Учёт организации, полного номера протокола, исполнителя, месяца и количества рабочих мест.
- Автоматический расчёт: 20 ₽ за рабочее место к получению, 10 ₽ — доля исполнителя; 100 ₽ за выполненную административную работу.
- Импорт накопительного архивного журнала с дедупликацией по индексу дела.
- Поиск по полному номеру протокола; при нескольких организациях показывает все совпадения.
- Контроль дат по партиям: передача первички, возврат, сдача отчёта и оплата.
- Статусы по записи: документы собраны, возвращены с подписи, подписаны, отсканированы.
- Ручная отметка даты выгрузки PDF на Яндекс.Диск (без автоматического подключения к облаку).
- Перенос старых записей из листа «2026 Реестр» и сводки партий.
- Экспорт копии исходного Excel-шаблона со всеми листами; индекс дела в отчёт не попадает.
- Отслеживание папки сканера и ручное сопоставление PDF с архивной записью.
- Резервная копия базы по кнопке и автоматически при закрытии приложения.
- OCR удалён полностью.

## Установка из исходников
1. Установить Python 3.12 (64-bit).
2. В PowerShell в папке проекта выполнить: `py -3.12 -m venv .venv`.
3. Активировать: `.venv\\Scripts\\activate`.
4. Установить зависимости: `pip install -r requirements.txt`.
5. Запустить: `python main.py`.

Для сборки EXE запустить `build_windows.bat`. Готовый файл появится в `dist\\YURKON Archive.exe`.

## Первый запуск
1. Нажать «Перенести старый Excel» и выбрать существующий `2026_учет_контор.xlsx`. Данные и партии будут перенесены в SQLite; повторный импорт той же книги не добавляет дубликаты.
2. Нажать «Импорт архива» и выбрать актуальный `Журнал_архивов.xlsx`. Новую накопительную версию можно импортировать повторно — одинаковые индексы не размножаются.
3. Добавлять новые записи через «Добавить запись».
4. Для отчёта выбрать исходный `2026_учет_контор.xlsx` как шаблон и сохранить отдельный файл. Исходник не изменяется.

## Папки сканирования
По умолчанию используются:
- `C:\\ЮРКОН\\Административка\\Сканы_новые`
- `C:\\ЮРКОН\\Административка\\Сканы_готовые`

Пути задаются в `app/config.py`.
