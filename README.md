# YURKON Archive

Локальное Windows-приложение для учёта организаций, первичной документации, архивных индексов и сканирования PDF.

## Возможности
- SQLite в профиле пользователя.
- Учёт организации, полного номера протокола, исполнителя, месяца и рабочих мест.
- Расчёт: 20 ₽ за рабочее место к получению, 10 ₽ — доля исполнителя; 100 ₽ за выполненную административную работу.
- Импорт накопительного архивного журнала без повторного добавления одинаковых строк.
- Поиск по протоколу с показом всех организаций при совпадающих номерах.
- Контроль дат и оплаты по партиям.
- Перенос старых записей из листа «2026 Реестр» и сводки партий.
- Экспорт копии исходного Excel-шаблона со всеми листами.
- Отслеживание папки сканера, ручное сопоставление PDF с архивной записью.
- OCR отсутствует.

## Установка
1. Установить Python 3.12 (64-bit).
2. В PowerShell в папке проекта выполнить: py -3.12 -m venv .venv
3. Активировать: .venv\\Scripts\\activate
4. Установить зависимости: pip install -r requirements.txt
5. Запустить: python main.py

## Первый запуск
1. Нажать «Перенести старый Excel» и выбрать существующий 2026_учет_контор.xlsx. Данные и партии будут перенесены в SQLite; повторный импорт не добавляет дубликаты.
2. Нажать «Импорт архива» и выбрать актуальный Журнал_архивов.xlsx. Новую накопительную версию можно импортировать повторно.
3. Добавлять новые записи через «Добавить запись».
4. Для отчёта выбрать исходный 2026_учет_контор.xlsx как шаблон и сохранить отдельный файл. Исходник не изменяется.

## Папки сканирования
По умолчанию: C:\\ЮРКОН\\Административка\\Сканы_новые и C:\\ЮРКОН\\Административка\\Сканы_готовые. Пути заданы в app/config.py.
